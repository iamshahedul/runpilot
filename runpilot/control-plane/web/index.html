Runtime Specifications

Node.js Node.js Runtime Engine
  • Supported Release Lines: 18.x, 20.x, 22.x
  • Package Managers: npm, pnpm, yarn
  • Frameworks: Express, Fastify, NestJS, Next.js, Socket.IO
  • Zero-Downtime Atomic Symlink Releases: current -> releases/<id>
  • Executed as: runpilot-app-<id> (Unprivileged)
Python Python Runtime Engine
  • Supported Release Lines: 3.10, 3.11, 3.12
  • Package Isolation: Dedicated per-release .venv
  • Manifests: requirements.txt, pyproject.toml
  • WSGI & ASGI Runners: Gunicorn, Uvicorn, Django, Flask, FastAPI
  • Executed as: runpilot-app-<id> (Unprivileged)
