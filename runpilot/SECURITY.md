# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in RunPilot:
1. Do NOT file a public issue on GitHub.
2. Email the core security team at `security@runpilot.org`.
3. Provide details regarding:
   - Affected component (Control Plane, Host Agent, Installer, Systemd integration)
   - Attack vector and reproduction steps
   - Potential impact
4. The RunPilot security team will acknowledge receipt within 48 hours and work with you on a coordinated disclosure timeline.
